👋 About Me

I'm Sagar Pathak, a student developer who learns by building.

I enjoy taking an idea from concept → interface → implementation → deployment, especially when the project has a strong visual or interactive component.

My public work ranges from full-stack applications and real-time systems to interactive 3D experiences, simulations, and mobile software.

I don't just want code that works. I want to understand why it works — and keep making it better.
