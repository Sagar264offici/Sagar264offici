# 👋 Hey, I'm Sagar.

I'm a student developer who learns by **building stupidly ambitious things and then figuring out how to make them work**.

I like projects where software stops feeling like a CRUD dashboard and starts feeling like an actual experience:

- interactive interfaces
- real-time systems
- 3D experiences
- Android applications
- simulations
- weird little experiments that somehow become real projects

I care about two things:

**1. Does it work?**  
**2. Can I make it better?**

Usually the answer to #2 is yes.
